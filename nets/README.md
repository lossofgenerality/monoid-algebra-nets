# The nets of this project, in the CCN Net Lab's layout

| Folder | Net | Status |
|---|---|---|
| `ownet/` | owNet | trained in Wolfram (Unit 4); no run in the lab yet |
| `tnparsernet/` | tnParserNet | drawn |
| `tnpolicynet/` | tnPolicyNet | drawn |
| `tnvaluenet/` | tnValueNet | drawn |

Each folder has `net.json` (the diagram from the net-diagram editor), `card.json` (what the published page is built from), `train/` (the generated training notebook), `runs/` (recorded training runs, none yet) and `writeup.md`. The layout is described in the lab's `docs/net-layout.md`. Published at https://lossofgenerality.github.io/ccn-nets/tensor-algebras/
