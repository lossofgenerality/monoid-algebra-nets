Net diagrams

Draw a small neural net and let the editor write the code that builds and trains it: a Wolfram notebook (our own code, and NetTrain) or a Python script (our own code, NumPy only). Its elements are feature groups, a hash, an input vector of slots, layers, dropout, joins and a softmax; it reads left to right, and wires are drawn from port to port.

The editor belongs to the CCN agent free-form language. This page shows the live copy, so every change made there appears here at once. Besides small feed-forward nets such as SubjectNet, it draws transformers: tokens, embeddings, encoders, decoders and their outputs. Under Examples are owNet (Unit 4) and the three TensorNets nets, tnParserNet, tnPolicyNet and tnValueNet, drawn from their definitions; for each, the editor counts the weights as Wolfram does and writes the net as a Wolfram NetGraph.
