add & LayerNorm residual connection

Each sub-layer of a transformer is wrapped as LayerNorm(x + Sublayer(x)): its input is added back to its output, then normalised. Lets the signal and its gradient pass straight through.

Unit 3 §8

arity

The number of arguments a symbol takes. add and mul have arity 2, sin 1, a number 0.

Unit 2 §3

atom

A symbol that is not an operator; in Unit 4, a, b, c or d.

Unit 4 §3

attention

An average of values, weighted by how well each key matches a query: softmax(QKᵀ/√dₖ)V. q = (1, 0), keys (1, 0) and (0, 1) give weights 0.670 and 0.330.

Unit 3 §3

backward generation BWD

Making integration data by drawing F and differentiating it; the pair is (F′, F). F = x sin x gives the problem sin x + x cos x.

Unit 2 §6

batch

The group of training examples whose gradients are averaged for one update. The paper of Unit 1 used 128 sentences.

Unit 1 §7

beam search

Decoding that keeps the B most likely partial outputs at every step, instead of only the best one. In the toy model, width 2 finds an output of probability 0.38 where greedy finds 0.24.

Unit 1 §8

BLEU

A score for machine translation that counts word sequences shared with reference translations. Reversing the source raised it from 25.9 to 30.6.

Unit 1 §6

Catalan number

Cₙ = (2n choose n)/(n + 1), the number of binary trees with n internal nodes. C₄ = 14.

Unit 2 §4

causal mask

A mask that stops position i from attending to positions after i. Row 1 of a 3 × 3 causal mask allows only position 1.

Unit 3 §5

counter owed subtrees

While reading prefix tokens, the number of subtrees still owed; it changes by arity − 1 per token. add 2 mul 3 add 5 2: 1, 2, 1, 2, 1, 2, 1, 0.

Unit 2 §3

cross-entropy

The loss −Σ qₖ log pₖ between a target distribution q and a predicted one p.

Unit 3 §11

D(e, n)

The number of ways to complete a tree with e empty slots and n internal nodes still to place. D(1, 2) = 6.

Unit 2 §4

decoder

The network that writes the output one token at a time, from the encoder’s summary and its own previous outputs.

Unit 1 §5

direct sum ⨁

The operator that joins the word lists of its two arguments; ⨂ distributes over it. (a⨁b)⨂c = a⨂c ⨁ b⨂c.

Unit 4 §4

embedding

A learned vector for each token of the vocabulary. EmbeddingLayer[d, V] stores a V × d matrix.

Unit 3 §10

encoder

The network that reads the whole input and summarises it.

Unit 1 §4

epoch

One pass through the whole training set.

Unit 1 §7

Equation 2 Lample and Charton

A recurrence for the number of expressions with n internal nodes. As printed it has p₁ where p₁² is needed; the forms agree only when p₁ is 0 or 1. L = 4, p₁ = 3, p₂ = 2, n = 3: true 19 756, printed 19 822.

Unit 2 §4

expand

Rewrite an expression as a ⨁ of words by distributing ⨂ over ⨁. (a⨁b)⨂(c⨁d) = ac ⨁ ad ⨁ bc ⨁ bd.

Unit 4 §4

feed-forward network FFN

The two-layer network applied to every position on its own: max(0, xW₁ + b₁)W₂ + b₂. dmodel → 2048 → dmodel in the base transformer.

Unit 3 §8

forget gate

The LSTM gate f that decides how much of the old memory to keep. After a pulse the memory decays like fᵗ.

Unit 1 §3

forward generation FWD

Making integration data by drawing f and asking a computer algebra system for its integral.

Unit 2 §6

gate LSTM

A vector of numbers between 0 and 1 that scales a signal: the input, forget and output gates of an LSTM.

Unit 1 §3

gradient clipping by norm

If the norm s of the whole gradient exceeds a threshold, rescale the gradient to that norm, keeping its direction. g = (6, 8), threshold 5: (3, 4).

Unit 1 §7

grammar-constrained decoding

Decoding that only allows tokens which keep the output a valid prefix tree. After ⨁ a b only </s> is allowed.

Unit 4 §7

greedy decoding

Decoding that always takes the most likely next token: a beam of width 1.

Unit 1 §8

hidden state

The vector h an LSTM shows to the next layer at each step.

Unit 1 §3

integration by parts IBP

∫ FG′ = FG − ∫ F′G; used to make new integration pairs from known ones. ∫ x cos x dx = x sin x + cos x.

Unit 2 §6

key, query, value

In attention, each position asks a query, and every position offers a key (to be matched) and a value (to be averaged).

Unit 3 §3

label smoothing

Training against the target (1 − ε)·onehot + ε/K instead of a one-hot target. K = 4, ε = 0.1: (0.025, 0.025, 0.925, 0.025).

Unit 3 §11

large Schröder number

Sₙ, the number of unary–binary trees with n internal nodes. S₂ = 6, S₃ = 22.

Unit 2 §4

LayerNorm

Normalise each position’s vector to mean 0 and variance 1, then apply a learned scale and shift. (1, 2, 3) → (−1.2238, 0, 1.2238) with ε = 0.001.

Unit 3 §8

learning rate

The size of each gradient step. 0.7 for 5 epochs, then halved every half epoch (Unit 1).

Unit 1 §7

length penalty

lp(Y) = ((5 + |Y|)/6)^α; dividing log-probabilities by it stops beam search from preferring short outputs. α = 0.6: lp(2) = 1.097, lp(8) = 1.590.

Unit 3 §13

LSTM

Long short-term memory: a recurrent cell with a memory updated by addition and controlled by gates. One step by hand: h′ = 0.1743, c′ = 0.2877.

Unit 1 §3

memory cell

The vector c an LSTM keeps for itself, updated as c′ = f c + i g.

Unit 1 §3

multi-head attention

h attentions in dmodel/h dimensions each, on different projections, joined and projected again. Base model: 8 heads of 64; 1 050 624 parameters.

Unit 3 §6

NetSharedArray

A Wolfram array that several layers use as one; here, the shared embedding and output weights.

Unit 3 §10

oracle

An exact symbolic program that labels training data and checks the net’s answers. equivalentQ in Unit 4; tnEquivalentQ in TensorNets.

Unit 4 §4

padding mask

A mask that hides padding at the end of short sequences.

Unit 3 §5

parameter

A number the training adjusts: a weight or a bias. The paper of Unit 1 has 384 112 000.

Unit 1 §9

positional encoding

A code added to each embedding to give attention the word order; sines and cosines of the position. PE(1) for dmodel = 4: (0.8415, 0.5403, 0.0100, 0.99995).

Unit 3 §7

prefix Polish) notation

Writing each operator before its arguments, so no parentheses are needed. 2 + 3 × (5 + 2) is add 2 mul 3 add 5 2.

Unit 2 §3

reversing the source

Feeding the input sentence backwards, which brings the first source and target words close together. T = 3: distances {1, 3, 5} instead of {3, 3, 3}.

Unit 1 §6

scaled dot product

A query–key score divided by √dₖ, so its variance is 1 rather than dₖ.

Unit 3 §4

shared embeddings

One weight matrix for the input embedding, the output embedding and the projection before the softmax.

Unit 3 §10

softmax

pₖ = e^{zₖ}/Σⱼ e^{zⱼ}: turns scores into positive probabilities that sum to 1. (2, 1, 0) → (0.665, 0.245, 0.090).

Unit 1 §5

teacher forcing

During training the decoder reads the correct previous token, not its own guess.

Unit 1 §5

tensor product ⨂

The operator that multiplies every word of its left argument by every word of its right, keeping order; not commutative. a⨂c and c⨂a are different words.

Unit 4 §4

thought vector

The final states of the encoder’s layers, which summarise the whole input. 2 × 4 × 1000 = 8000 numbers in the paper of Unit 1.

Unit 1 §4

uniform sampling of trees

Drawing every tree with n internal nodes equally often, by choosing each node with probability proportional to D(e, n). First choice for n = 2: unary 1/3, binary 2/3.

Unit 2 §5

verification

Checking an answer exactly instead of trusting the net: by differentiating (Unit 2) or by the oracle (Unit 4). Beam 4 with checking: 97 % of test expressions solved in Unit 4.

Unit 2 §7

warm-up

A learning rate that rises linearly at the start of training, then falls. Peak 6.99 × 10⁻⁴ at step 4000 for dmodel = 512.

Unit 3 §12

word in ⨂/⨁ algebra

An ordered ⨂-product of atoms; an expanded expression is a ⨁ of words. a⨂b⨂d.
